**Modify `scripts/main.gd`:**

Add `_setup_mode_manager()` called via `call_deferred` at the end of `_ready()`. This ensures it runs after both XR init and the scene tree are fully ready:

```gdscript
extends Node3D

var xr_interface: XRInterface
var xr_active: bool = false

func _ready():
    if OS.get_name() == "macOS":
        print("macOS detected - forcing flat screen preview mode")
        _enable_flat_screen()
    else:
        xr_interface = XRServer.find_interface("OpenXR")
        if xr_interface and xr_interface.initialize():
            print("OpenXR initialized - VR mode active")
            DisplayServer.window_set_vsync_mode(DisplayServer.VSYNC_DISABLED)
            get_viewport().use_xr = true
            xr_active = true
        else:
            print("No XR runtime - flat screen preview mode")
            _enable_flat_screen()

    # Set up ModeManager after XR/flat-screen init, deferred so scene tree is ready
    call_deferred("_setup_mode_manager")

func _enable_flat_screen():
    get_viewport().use_xr = false
    $VRScene/FallbackCamera3D.current = true
    print("Flat screen camera active")

func _setup_mode_manager() -> void:
    var container := $VRScene/ModeContainer
    ModeManager.set_container(container)
    ModeManager.switch_to("spectrum_bars")
```

Key changes to main.gd:
- Removed early `return` from macOS branch so `_setup_mode_manager` deferred call always gets registered
- Added `call_deferred("_setup_mode_manager")` at end of `_ready()` -- runs after full scene tree init
- `_setup_mode_manager` finds ModeContainer in VRScene and calls switch_to("spectrum_bars")
- The `else` block wraps the XR init path (previously relied on macOS early return)
