Investigate whether Rekordbox caches stem audio files to disk. Research strongly indicates this is a dead end (stems are real-time CPU processing, .3EX files are ML embeddings). Cap this investigation at 30 minutes.

Steps:
1. Search for audio files in Rekordbox data directories:
   - `find ~/Library/Pioneer/rekordbox/ -type f \( -name "*.wav" -o -name "*.flac" -o -name "*.mp3" -o -name "*.ogg" -o -name "*.aac" -o -name "*.m4a" \) 2>/dev/null`
   - `find ~/Music/rekordbox/ -type f \( -name "*.wav" -o -name "*.flac" -o -name "*.mp3" \) 2>/dev/null`
2. Inspect a .3EX file from `~/Library/Pioneer/rekordbox/share/PIONEER/USBANLZ/` to confirm it contains ML embeddings, not audio:
   - `find ~/Library/Pioneer/rekordbox/share/PIONEER/USBANLZ/ -name "*.3EX" | head -1` to find one
   - `xxd {found_file} | head -10` to inspect binary header
   - `file {found_file}` to check file type detection
   - `ls -la {found_file}` to confirm size (~5.5KB, far too small for audio)
3. Check the Sampler/Capture directory: `ls -la ~/Music/rekordbox/Sampler/Capture/` (expected empty)
4. Search for any hidden or non-obvious audio caches:
   - `find ~/Library/Pioneer/ -type f -size +1M 2>/dev/null | head -20` (audio files would be >1MB)
   - `find ~/Library/Caches/ -path "*rekordbox*" -o -path "*Pioneer*" 2>/dev/null | head -20`

  <action>
Install BlackHole 16ch and configure audio routing so Rekordbox output can be captured.

Claude automates:
1. Run `brew install blackhole-16ch` to install BlackHole virtual audio driver
2. Run `ffmpeg -f avfoundation -list_devices true -i "" 2>&1` to find BlackHole device index
3. After user confirms routing setup, record a 5-second test capture:
   `ffmpeg -f avfoundation -i ":{blackhole_device_index}" -acodec pcm_s16le -ar 44100 -t 5 /tmp/blackhole_test.wav`
4. Verify capture is non-silent: `sox /tmp/blackhole_test.wav -n stats 2>&1 | head -5`
5. Update FINDINGS.md `## BlackHole Setup` section with: BlackHole device index, brew install output, test capture sox stats confirming non-silent audio

User must do (macOS GUI required):
1. Open Audio MIDI Setup (Spotlight: "Audio MIDI Setup")
2. Click "+" at bottom-left, select "Create Multi-Output Device"
3. Check both "BlackHole 16ch" and physical output (headphones/speakers)
4. Open Rekordbox DJ Pro > Preferences > Audio > set output to "BlackHole 16ch" or Multi-Output Device
5. Rekordbox Preferences > Extensions > STEMS > enable, set "Prioritize sound quality"
6. Play a track in Rekordbox during the 5-second test capture window
  </action>
