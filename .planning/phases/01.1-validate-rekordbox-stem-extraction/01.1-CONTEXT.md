<decisions>
## Implementation Decisions

### Validation criteria
- Goal: confirm Rekordbox's 4 stem outputs are separately capturable as individual audio streams on macOS
- Proof level: stems audibly separate — play back each captured stem to verify isolation
- No Godot integration needed — just confirm the audio can be captured
- Manual process is fine (no automation required)

### Key constraint discovered
- Rekordbox only has a single master audio output — no per-stem output routing
- Stems are real-time processing only, designed for live mute/solo during DJ performance
- No file export of individual stems — they are not written to disk via any standard Rekordbox feature
- This means the original BlackHole multi-channel routing plan won't work as-is

### Investigation priority: Rekordbox stem cache
- Primary approach: hunt for Rekordbox's pre-analyzed stem cache files on disk
- When Rekordbox "pre-analyzes" stems, it must cache the separation results somewhere in its data directories
- If cache files are in a readable audio format, this is the cleanest solution — Rekordbox's own separation quality, no external tools
- Rekordbox data likely lives under `/Users/kquillen/Music/rekordbox/` or `~/Library/Pioneer/rekordbox/`

### Fallback investigation: workarounds
- If stem cache is not accessible/readable: investigate MIDI/OSC control, third-party tools, or JACK routing
- Spend up to a few hours on workaround investigation before declaring the approach blocked
- Solo-and-capture via BlackHole is a fallback (play 4 times, solo one stem each time)
- Demucs pre-separation remains the known-working baseline (already used for test stems)

### Routing tool
- BlackHole (free, open-source) for virtual audio routing
- Not yet installed — installation is part of the spike
- BlackHole only needed if stem cache approach fails and we need to capture audio output

### Environment
- Rekordbox DJ Pro: already installed and licensed on this Mac
- BlackHole: not yet installed
- macOS development machine
- Rekordbox stem settings path: `/Users/kquillen/Music/rekordbox/Sampler/Capture` (currently empty)

### Claude's Discretion
- Order of investigation steps within the spike
- Which Rekordbox data directories to search
- How to verify stem audio quality once captured
- Documentation format for findings

</decisions>
