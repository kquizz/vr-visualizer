<feature>
  <name>NSEEL Interpreter</name>
  <files>scripts/milkdrop/nseel_interpreter.gd, scripts/milkdrop/test_nseel.gd</files>
  <behavior>
    Tokenizer:
    - "3.14" -> NUMBER(3.14)
    - "zoom" -> IDENTIFIER("zoom")
    - "zoom = zoom + 0.1 * sin(time);" -> correct token sequence
    - "+=" -> PLUS_ASSIGN, "==" -> EQUAL, "<=" -> LESS_EQUAL
    - "//" comments are stripped
    - Empty input -> [EOF]

    Parser (produces AST):
    - "42" -> NumberLiteral(42)
    - "zoom" -> Variable("zoom")
    - "zoom = 1.0" -> Assignment(Variable("zoom"), NumberLiteral(1.0))
    - "zoom += 0.1" -> CompoundAssignment(Variable("zoom"), "+", NumberLiteral(0.1))
    - "a + b * c" -> BinaryOp("+", Variable("a"), BinaryOp("*", Variable("b"), Variable("c"))) (precedence)
    - "-x" -> UnaryOp("-", Variable("x"))
    - "sin(3.14)" -> FunctionCall("sin", [NumberLiteral(3.14)])
    - "if(a, b, c)" -> FunctionCall("if", [Variable("a"), Variable("b"), Variable("c")])
    - "a = 1; b = 2" -> Block([Assignment(...), Assignment(...)])

    Evaluator (with variable pool Dictionary):
    - "42" evaluates to 42.0
    - Pool {"x": 5.0}, "x" evaluates to 5.0
    - "x = 3" sets pool["x"] = 3.0, returns 3.0
    - "x += 1" with pool["x"]=5 sets pool["x"]=6.0
    - sin(0) ~= 0, cos(0) ~= 1, sqrt(4) == 2, pow(2,3) == 8
    - abs(-5) == 5, sign(-3) == -1, floor(1.7) == 1, ceil(1.3) == 2
    - min(3,5) == 3, max(3,5) == 5, sqr(4) == 16
    - if(1, 10, 20) == 10, if(0, 10, 20) == 20
    - above(5, 3) == 1, below(2, 3) == 1, equal(1.0, 1.0) == 1
    - atan2(1, 0) ~= PI/2, log(E) ~= 1, log10(100) ~= 2
    - rand(100) returns value in 0..100
    - sigmoid(0, 1) == 0.5
    - bor(5, 3) == 7, band(5, 3) == 1, bnot(0) == -1
    - "a = sin(time * 0.5); zoom = 1.0 + a * 0.1" with pool{"time":3.14} evaluates correctly

    Variable scoping:
    - Per-frame pool and per-vertex pool are separate Dictionaries
    - q1-q32 copied FROM per-frame pool TO per-vertex pool (not referenced)
    - Modifying q5 in per-vertex pool does NOT change per-frame pool's q5
    - Custom variable "my_var" created in per-frame pool does NOT exist in per-vertex pool
    - Undefined variables evaluate to 0.0 (not error)
    - Integer operators (%, |, &) convert operands to int before computing
  </behavior>
  <implementation>
    Build in three phases using RED-GREEN-REFACTOR:

    Phase A - Tokenizer:
    Create enum TokenType with: NUMBER, IDENTIFIER, PLUS, MINUS, STAR, SLASH, PERCENT, ASSIGN, PLUS_ASSIGN, MINUS_ASSIGN, STAR_ASSIGN, SLASH_ASSIGN, EQUAL, NOT_EQUAL, LESS, LESS_EQUAL, GREATER, GREATER_EQUAL, LPAREN, RPAREN, COMMA, SEMICOLON, PIPE, AMPERSAND, EOF.
    Create Token class with type, value (String), number_value (float).
    Create tokenize(code: String) -> Array function.
    Handle: whitespace skipping, // comments, number literals (including ".5" and "3."), identifiers (a-z, A-Z, _, 0-9 after first), two-char operators (+=, -=, *=, /=, ==, !=, <=, >=), single-char operators.

    Phase B - Parser:
    Create AST node classes: NumberLiteral, Variable, BinaryOp, UnaryOp, FunctionCall, Assignment, CompoundAssignment, Block.
    Each node class has an evaluate(pool: Dictionary) method (or use a separate evaluator).
    Implement recursive descent parser with operator precedence:
      - Lowest: assignment (=, +=, -=, *=, /=)
      - Comparison (==, !=, <, <=, >, >=)
      - Addition (+, -)
      - Multiplication (*, /, %)
      - Unary (-, +)
      - Primary (number, variable, function call, parenthesized expression)
    Semicolons create Block nodes. Trailing semicolons are OK.

    Phase C - Evaluator + Built-in Functions:
    Create evaluate(code: String, pool: Dictionary) -> float as the main public API.
    Internally: tokenize -> parse -> evaluate AST.
    Add compile(code: String) -> AST node for pre-compilation (parse once, evaluate many times).
    Add evaluate_compiled(ast, pool: Dictionary) -> float for fast per-frame evaluation.
    Built-in functions (25): sin, cos, tan, asin, acos, atan, atan2, sqrt, pow, exp, log, log10, abs, sign, floor, ceil, int, min, max, sqr, invsqrt, rand, if, sigmoid, above, below, equal, bor, band, bnot.
    Variable pool: Dictionary[String, float]. Undefined variables return 0.0. Assignment creates/updates entries.
    Multi-statement blocks: evaluate each statement left to right, return last statement's value.

    The test file (test_nseel.gd) should be a GDScript that can be run with:
      godot --headless --script scripts/milkdrop/test_nseel.gd
    It should print PASS/FAIL for each test case and exit with code 0 on all pass, 1 on any failure.
    Use a simple assert_eq/assert_near pattern (no external test framework dependency).
  </implementation>
