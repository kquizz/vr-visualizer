    Create `scripts/milkdrop/audio_bridge.gd` that maps AudioManager data to MilkDrop's expected audio variables.

    ```gdscript
    class_name MilkdropAudioBridge
    extends RefCounted

    # Immediate audio values (fast response)
    var bass: float = 0.0
    var mid: float = 0.0
    var treb: float = 0.0

    # Attenuated values (slower decay for smooth envelope)
    var bass_att: float = 0.0
    var mid_att: float = 0.0
    var treb_att: float = 0.0

    # Smoothing factor for _att variants (per CONTEXT.md)
    const ATT_DECAY := 0.92

    func update() -> void:
        var data: AudioData = AudioManager.audio_data
        if data == null or not AudioManager.has_signal:
            return

        # Immediate values per CONTEXT.md locked mapping:
        # bass = grouped[0] (LOW: sub-bass + bass)
        bass = data.grouped[0]
        # mid = (grouped[1] + grouped[2]) * 0.5 (MID_LOW + MID_HIGH averaged)
        mid = (data.grouped[1] + data.grouped[2]) * 0.5
        # treb = grouped[3] (HIGH: brilliance)
        treb = data.grouped[3]

        # _att variants: exponential smoothing (rise instantly, decay slowly)
        bass_att = maxf(bass, bass_att * ATT_DECAY)
        mid_att = maxf(mid, mid_att * ATT_DECAY)
        treb_att = maxf(treb, treb_att * ATT_DECAY)

    # Inject audio variables into a MilkDrop equation variable pool
    func inject_into_pool(pool: Dictionary) -> void:
        pool["bass"] = bass
        pool["mid"] = mid
        pool["treb"] = treb
        pool["bass_att"] = bass_att
        pool["mid_att"] = mid_att
        pool["treb_att"] = treb_att
    ```

    Key requirements:
    - Uses AudioManager autoload singleton directly (not passed in)
    - ATT_DECAY = 0.92 for smooth envelope
    - bass = grouped[0], mid = (grouped[1]+grouped[2])*0.5, treb = grouped[3] -- per locked CONTEXT.md decisions
    - inject_into_pool() writes all 6 audio vars into a Dictionary for NSEEL equation evaluation
    - Gracefully handles null audio_data or no signal (returns without updating)
  </action>
