    **scenes/modes/milkdrop.gd** -- Thin wrapper script for the scene root. The actual rendering logic is in MilkdropRenderer which this node extends.

    Since MilkdropRenderer extends Node3D and expects specific child node names (SubViewportA, SubViewportB, GridMeshInstance, WarpDome), the simplest approach is to make the scene root script extend MilkdropRenderer and override _initialize() to build the scene tree in code.

    Given past experience in Phase 4 (where .tscn hand-writing caused issues with ext_resource ordering), build the scene ENTIRELY in code. The .tscn should just be a minimal Node3D with the script attached. Override _initialize() in milkdrop.gd to build the scene tree:

    ```gdscript
    extends MilkdropRenderer

    # Scene entry point for MilkDrop mode.
    # MilkdropRenderer handles all rendering logic.
    # This script builds the scene tree in code to avoid .tscn ext_resource ordering issues.

    func _initialize() -> void:
        # SubViewport A (write target)
        var vp_a := SubViewport.new()
        vp_a.name = "SubViewportA"
        vp_a.size = Vector2i(VIEWPORT_SIZE, VIEWPORT_SIZE)
        vp_a.transparent_bg = false
        vp_a.render_target_update_mode = SubViewport.UPDATE_ALWAYS
        add_child(vp_a)

        # Grid mesh instance inside SubViewportA
        var grid_inst := MeshInstance2D.new()
        grid_inst.name = "GridMeshInstance"
        var warp_shader := load("res://shaders/milkdrop_warp.gdshader")
        var warp_mat := ShaderMaterial.new()
        warp_mat.shader = warp_shader
        grid_inst.material = warp_mat
        vp_a.add_child(grid_inst)

        # SubViewport B (read source for ping-pong)
        var vp_b := SubViewport.new()
        vp_b.name = "SubViewportB"
        vp_b.size = Vector2i(VIEWPORT_SIZE, VIEWPORT_SIZE)
        vp_b.transparent_bg = false
        vp_b.render_target_update_mode = SubViewport.UPDATE_ALWAYS
        add_child(vp_b)

        # WarpDome (inverted sphere)
        var dome := MeshInstance3D.new()
        dome.name = "WarpDome"
        var sphere := SphereMesh.new()
        sphere.radius = 6.0
        sphere.height = 12.0
        sphere.radial_segments = 64
        sphere.rings = 32
        sphere.flip_faces = true
        dome.mesh = sphere
        var display_shader := load("res://shaders/milkdrop_display.gdshader")
        var display_mat := ShaderMaterial.new()
        display_mat.shader = display_shader
        dome.material_override = display_mat
        dome.position.y = 1.7  # Camera height
        add_child(dome)

        # Now call parent _initialize() which wires up the references
        super._initialize()
    ```

    MilkdropRenderer._initialize() does $SubViewportA etc. Since we build nodes before calling super, the $ references work.
