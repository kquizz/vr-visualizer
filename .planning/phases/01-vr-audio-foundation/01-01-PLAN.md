Create the scene hierarchy and startup script:

**scripts/main.gd** - Dual-mode XR startup:
```gdscript
extends Node3D

var xr_interface: XRInterface
var xr_active: bool = false

func _ready():
    xr_interface = XRServer.find_interface("OpenXR")
    if xr_interface and xr_interface.is_initialized():
        print("OpenXR initialized - VR mode active")
        DisplayServer.window_set_vsync_mode(DisplayServer.VSYNC_DISABLED)
        get_viewport().use_xr = true
        xr_active = true
    else:
        print("No XR runtime - flat screen preview mode")
        $VRScene/FallbackCamera3D.current = true
```

**scenes/main.tscn** - Entry point scene:
- Root: Node3D with main.gd script attached
- Child: instance of vr_scene.tscn

**scripts/fallback_camera.gd** - Mouse look for flat-screen mode:
```gdscript
extends Camera3D

var mouse_sensitivity := 0.002
var pitch := 0.0
var yaw := 0.0

func _ready():
    if current:
        Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

func _unhandled_input(event: InputEvent):
    if not current:
        return
    if event is InputEventMouseMotion:
        yaw -= event.relative.x * mouse_sensitivity
        pitch -= event.relative.y * mouse_sensitivity
        pitch = clamp(pitch, -PI/2, PI/2)
        transform.basis = Basis()
        rotate_y(yaw)
        rotate_object_local(Vector3.RIGHT, pitch)
    if event is InputEventKey and event.pressed and event.keycode == KEY_ESCAPE:
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
```

For the skybox, use ProceduralSkyMaterial with very dark colors to simulate deep space. A real panorama texture (AllSky Free or similar) can be swapped in later -- the procedural sky establishes the environment without requiring an external asset download.

The XROrigin3D is at world origin. XRCamera3D at y=1.7 (standing height). No movement scripts, no locomotion -- static viewpoint per VR-03. The FallbackCamera3D enables development without a headset per user decision.
