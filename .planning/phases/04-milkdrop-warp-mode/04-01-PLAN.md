**shaders/warp_feedback.gdshader** -- canvas_item shader for the feedback loop:
- `shader_type canvas_item;`
- Uniforms (all with hint_range for editor tuning):
  - `uniform sampler2D prev_frame : filter_linear, repeat_enable;` -- previous frame from SubViewportB
  - `uniform float warp_zoom : hint_range(0.9, 1.2) = 1.0;` -- bass-driven zoom
  - `uniform float warp_rotation : hint_range(-0.1, 0.1) = 0.0;` -- mids-driven rotation
  - `uniform float warp_dx : hint_range(-0.02, 0.02) = 0.0;` -- horizontal translation
  - `uniform float warp_dy : hint_range(-0.02, 0.02) = 0.0;` -- vertical translation
  - `uniform float decay : hint_range(0.8, 1.0) = 0.97;` -- frame retention (0.97 = long trails)
  - `uniform float hue_shift : hint_range(0.0, 1.0) = 0.0;` -- highs-driven color shift
  - `uniform float brightness : hint_range(0.5, 2.0) = 1.0;` -- highs-driven brightness
  - `uniform float master_intensity : hint_range(0.0, 2.0) = 1.0;` -- overall energy scaler
  - `uniform sampler2D noise_tex : filter_linear;` -- NoiseTexture2D for stability resets
  - `uniform float noise_amount : hint_range(0.0, 0.1) = 0.0;` -- noise injection strength
  - `uniform float audio_inject_amount : hint_range(0.0, 0.5) = 0.1;` -- audio color injection opacity
  - `uniform vec3 audio_color = vec3(1.0, 0.3, 0.1);` -- frequency-mapped color
  - `uniform bool symmetry_enabled = true;` -- kaleidoscope fold toggle

- Include `rgb2hsv()` and `hsv2rgb()` helper functions (use the exact implementations from 04-RESEARCH.md Code Examples section)

- `fragment()` function logic in order:
  1. Optional symmetry: if `symmetry_enabled`, fold UV via kaleidoscope -- convert to polar from center (0.5, 0.5), apply `angle = mod(angle, PI / 2.0)` for 4-fold symmetry, convert back to cartesian + 0.5
  2. UV warp: convert UV to polar coordinates from center, divide radius by `warp_zoom`, add `warp_rotation` to angle, convert back, add `vec2(warp_dx, warp_dy)` translation
  3. Sample `prev_frame` at warped UV
  4. Combined decay: `prev.rgb = (prev.rgb - vec3(0.002)) * decay;` (multiplicative + subtractive prevents accumulation drift)
  5. Hue shift: convert to HSV, `hsv.x = fract(hsv.x + hue_shift)`, multiply `hsv.z` by brightness, convert back to RGB
  6. Audio color injection: `prev.rgb += audio_color * audio_inject_amount * master_intensity;`
  7. Noise injection: sample `noise_tex` at `uv + vec2(TIME * 0.01)`, add `noise.rgb * noise_amount`
  8. Final output: `COLOR = vec4(clamp(prev.rgb, 0.0, 1.0), 1.0);`

**scenes/modes/warp.gd** -- Warp mode script:
```gdscript
extends Node3D

@export_group("Bass Response")
@export_enum("Punchy", "Smooth", "Intensity-Scaled") var bass_mode: int = 0
@export var zoom_intensity: float = 0.15

@export_group("Decay")

@export_group("Stability")
@export var stability_reset_enabled: bool = true
@export var reset_interval: float = 45.0

@export_group("Symmetry")
@export var symmetry_enabled: bool = true
```

Key implementation details for warp.gd:
- `var _shader_material: ShaderMaterial` -- cached reference to `$PingPongSystem/SubViewportA/ColorRect.material`
- In `_ready()`:
  1. Cache `_shader_material = $PingPongSystem/SubViewportA/ColorRect.material`
  2. Connect `$ResetTimer.timeout` signal to `_on_reset_timer_timeout`
  3. Set `$ResetTimer.wait_time = reset_interval`
  4. Use `call_deferred("_setup_viewport_textures")` for safe ViewportTexture assignment
- `_setup_viewport_textures()`:
  1. Create ViewportTexture for SubViewportB, assign to `_shader_material.set_shader_parameter("prev_frame", vt_b)`
  2. Create ViewportTexture for SubViewportA, assign to `$PingPongSystem/SubViewportB/CopySprite.texture`
  3. Create ViewportTexture for SubViewportA, assign to `$WarpDome.material_override.set_shader_parameter("warp_texture", vt_a_dome)`
  4. Note: ViewportTexture.new() requires setting `viewport_path` relative to the scene tree root (use `get_path_to()`)
- `_process(delta)`: reads `AudioManager.audio_data`, calls `_update_warp_params(data, delta)` -- full audio mapping logic from RESEARCH.md Pattern 4
  - Bass (grouped[0]) -> warp_zoom based on bass_mode: Punchy = `1.0 + bass * zoom_intensity`, Smooth = `1.0 + bass * zoom_intensity * 0.3`, Intensity-Scaled = `1.0 + bass * zoom_intensity * bass`
  - Mids ((grouped[1] + grouped[2]) * 0.5) -> warp_rotation = `mids * 0.03`
  - Highs (grouped[3]) -> hue_shift = `highs * 0.005`, brightness = `1.0 + highs * 0.3`
  - Decay based on decay_mode: Long Trails = 0.975, Quick Dissolve = 0.85, Audio-Driven = `lerpf(0.98, 0.85, energy)`
  - Master intensity = `0.3 + energy * 0.7` (never fully zero)
  - Audio color via `_frequency_to_color(bass, mids, highs)` returning Vector3: bass=warm (r=bass*0.8+mids*0.2), mids=green (g=mids*0.5+bass*0.3), highs=cool (b=highs*0.8+mids*0.2), normalized * 0.8
  - Set all uniforms on `_shader_material` via `set_shader_parameter()`
  - Also set `symmetry_enabled` uniform
- `_on_reset_timer_timeout()`: if `stability_reset_enabled`, set `noise_amount` to 0.05, tween back to 0.0 over 2.0 seconds using `create_tween().tween_method()`
- `_update_idle()` (when `not AudioManager.has_signal`): set gentle defaults -- zoom=1.0, rotation=0.005 (slow constant spin), decay=0.975, master_intensity=0.3, audio_inject_amount=0.02 with a slowly cycling color based on TIME
